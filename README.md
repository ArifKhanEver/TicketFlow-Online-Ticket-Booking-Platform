# TicketFlow - Online Ticket Booking Platform

## 📌 Project Purpose
TicketFlow is a modern, dynamic, and intuitive online ticket booking platform designed to provide a seamless experience for discovering and booking travel tickets (Bus, Train, Launch, and Plane). The platform bridges the gap between travelers and transport vendors, ensuring a hassle-free booking process with real-time updates and secure payments.

## 🚀 Key Features
- **Role-Based Dashboards:** Distinct and secure dashboard experiences for Users, Vendors, and Admins.
- **Secure Authentication:** Seamless Registration, Login, and Google Social Login powered by BetterAuth.
- **Dynamic Booking System:** Real-time ticket quantity updates, booking countdowns, and Stripe payment gateway integration.
- **Vendor Management:** Vendors can add, update, delete tickets, and manage booking requests (Accept/Reject).
- **Admin Controls:** Admins can approve/reject tickets, manage user roles, mark vendors as fraud, and select up to 6 tickets for homepage advertisement.
- **Advanced Search & Filtering:** Filter tickets by transport type and search by 'From' and 'To' locations.
